# Guide professeur — Portail Hall AERO

Ce guide explique comment un **professeur** se connecte et réserve une machine du
hall aéronautique.

---

## 1. Se connecter

1. Ouvrir le site dans un navigateur. portail-aero.alwaysdata.net
2. Saisir la **clé d'accès professeur** dans le champ unique.
3. Cliquer sur **« Se connecter »**.

> Une seule clé suffit : si elle correspond à la clé **professeur**, vous arrivez
> directement sur le **Planning du Hall Aéronautique** (l'espace professeur).
> Cochez « Rester connecté sur ce poste » seulement sur un ordinateur de confiance.

L'écran affiche, à gauche, la liste des **machines** et, au centre, le
**calendrier** des réservations.

---

## 2. Réserver une machine

La réservation se fait par **glisser-déposer** d'une machine vers un créneau du
calendrier.

1. Dans la colonne **« Machines »** (à gauche), repérer la machine voulue.
2. **Glisser** la machine (cliquer-maintenir) et la **déposer** sur le jour/créneau
   souhaité dans le calendrier.
3. Une fenêtre **« Réserver »** s'ouvre. Renseigner :
   - le **Professeur** (obligatoire) ;
   - la **Classe** (obligatoire) ;
   - une **Description** (facultative, ex. « Usinage pièce projet tuteuré »).
4. Cliquer sur **« Confirmer »**.

### Créneau déjà réservé

Si la machine est déjà réservée sur ce créneau, une **alerte** indique qui l'a
réservée (professeur, classe, description). Vous pouvez choisir de réserver quand
même, mais évitez les doublons sur une même machine.

---

## 3. Réservation récurrente (répéter)

Pour réserver le même créneau sur plusieurs dates (ex. tous les mardis matin) :

1. Dans la fenêtre **« Réserver »**, choisir d'abord le **Professeur** et la
   **Classe** (ils s'appliquent à toutes les occurrences).
2. Cliquer sur **« Répéter »**.
3. Régler la récurrence (fréquence, dates), puis confirmer.

> Les **week-ends** et **jours fériés français** sont automatiquement exclus. Les
> créneaux déjà occupés sur la même machine sont **ignorés** (signalés) au lieu de
> bloquer toute la série. Un récapitulatif indique le nombre de réservations
> créées, ignorées et en échec.

---

## 4. Consulter, modifier ou supprimer une réservation

1. **Cliquer sur une réservation** dans le calendrier : une fenêtre affiche le
   détail (machine, professeur, classe, horaire, description).
2. Boutons disponibles :
   - **Modifier** — changer le professeur, la classe ou la description, puis
     **« Enregistrer »**. (La machine et l'horaire ne se changent pas ici ; pour
     déplacer le créneau, voir ci-dessous.)
   - **Supprimer** — retire la réservation (avec confirmation).
   - **Fermer** — quitter sans rien changer.

### Déplacer une réservation

Pour changer le créneau d'une réservation existante, **glissez-la** directement
vers un autre jour/créneau dans le calendrier. Elle est recalée sur la demi-journée
correspondante et enregistrée automatiquement.

---

## 5. Se déconnecter

Cliquer sur **« Se déconnecter »** en haut à droite de l'espace professeur. Vous
revenez à la page de connexion.

> Le bouton de changement de thème (clair / sombre) est disponible à côté de la
> déconnexion.
